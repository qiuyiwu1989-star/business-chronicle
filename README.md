# 商业通鉴 · 五本书里的百年商业史

> 从美第奇的汇票到 ChatGPT。五本书、五条线叠在一起，让百年商业史规律自现。
>
> 线上：**https://chronicle.qiuyiwu.com**

这不是一本商业史知识库，是一台**练判断的机器**。

## 它做了什么

同一个百年，五本书各看一面。把它们叠成五条可对照的时间线：

| 线 | 看什么 | 来源 |
|---|---|---|
| **理论线** 34 节点 | 思想：百年战略理论的学派之争 | 《经营战略全史》三谷宏治 |
| **企业线** 49 节点 | 现场：革新者如何把发明推向大众 | 《他们创造了美国》哈罗德·埃文斯 |
| **模式线** 29 节点 | 赚钱方式的进化与转世 | 《商业模式全史》三谷宏治 |
| **组织线** 20 节点 | 组织形态与管理实践的进化 | 《管理百年》斯图尔特·克雷纳 |
| **著作线** 34 部 | 思想如何出版成经典 | — |

横切透镜来自《新经营学》：商业模式 = 目标 × 价值 × 能力 × 收益。

## 与一般商业史读物的区别：决策现场

每个历史节点不只有"发生了什么"，还原了当事人的**决策现场**五问：

- **当时的局面** — 他面对的真实约束与选项
- **关键抉择** — 他选了什么，反共识点在哪
- **同时代的对照** — 谁做了相反的选择，结局如何 ← *这是本站的灵魂*
- **后续命运** — 这个优势后来如何被绕过或反噬
- **今日回声** — 同一个结构，今天对应什么生意

历史书通常只写赢家。**每个赢家旁边放一个真实的输家**，判断力才练得出来。

## 功能

- **五轨时间线** — 单线细读或五线对照，带时代分层
- **节点卡片库** — 四类现场节点 + 著作维度，按学派/要素筛选与搜索
- **关系图谱** — 谁影响谁、谁批判谁的理论谱系
- **学派之争** — 定位学派 vs 能力学派正面对比
- **以史鉴今** — 七条百年规律 + 战略判断仪表盘
- **测验** — 10 道知识题 + 8 道情景题（从"背"升级到"用"）
- **术语词典 42 条 · 人物志**
- 深浅色主题、学习进度记录（本地存储）、PWA 可安装离线访问

## 技术

纯静态：HTML + CSS + 原生 JS。**零依赖、零构建、零后端**。

```bash
node server.js     # → http://localhost:3000
node tools/validate.js   # 数据完整性校验
```

- `data.v22.js` — 全部内容数据（单一数据源）
- `app.v22.js` — 全部渲染逻辑
- `style.v22.css` — 样式
- `tools/validate.js` — 校验 rel 指向、字段完整性、内容红线

## 内容纪律

本站内容是对公开史实的事实性整理，**非原书文字摘录**。写作红线：

1. **只搬运不发明** — 不虚构史实、数据、引文；不确定的精确数字一律改为定性表述
2. **不杜撰引语** — 历史人物的话一律转述，不加引号直接引用
3. **对照者必须真实** — 想不出真实对照者就写"同时代普遍做法"，不编造公司名
4. **近期事实从严** — 2020 年后只写已成定论的部分
