# 002: 中国商业史对照线

## 要什么
新增第六条时间线 `CHINA`：从票号到大模型的中国商业现场，与既有五条线**并置对照**。

读者要能看到：同一个时间断面上，西方在做什么、中国在做什么，以及同一个商业结构（信任、分工、渠道、平台）在两种制度环境里长成了什么不同形状。

- 约 24 个节点，覆盖 1823 票号 → 2023 大模型。
- 节点结构与现有三条现场线**完全一致**（year/company/event/brief/bg/result/lesson/deep/rel），零新增字段——渲染逻辑可直接复用。
- `deep.echo` 的落点是**中西对照**：这个中国现场对应西方哪个节点，差别在哪、为什么。
- 时间线新增「中国线」轨道与筛选；卡片库新增「中国」分类；首页数字与进度条自动纳入。

## 不做什么
- **不改站点主叙事**。站名仍是"五本书里的百年商业史"。中国线在 UI 上明确标注为**对照线**（不来自那五本书，是站方补的对照），不冒充书里的内容。
- 不做政治史、不做制度评价、不做人物功过评判。只写**商业结构与经营抉择**。
- 不写正在进行中的监管案件、企业家个人司法案件、未定论的商业纠纷。
- 不新增 CSS 组件，复用既有 tcard / 弹层 / chip 样式。

## 实现约束
- 数据放 `data.v22.js` 的 `const CHINA = [...]`，位置在 ORGS 之后、ELEMENTS 之前。
- 轨道色沿用一个未被占用的色值（现有：理论 accent / 企业 warn / 模式 info / 组织 ok）→ 中国线用 `--err`（#D63A63）。
- `rel` 仍指向 THEORIES 的 key，让中国节点也能挂上西方理论。
- `tools/validate.js` 需把 CHINA 纳入校验；`tools/build-seo.js` 需把 CHINA 导出进 llms-full.txt。
- 首页 hero 数字、学习进度、stats 均由数据生成，加线后自动更新，无需改硬编码。

## 内容红线（在 CONTEXT.md 六条之外，本 spec 额外加严）
1. **政治中立**：只描述商业事实与经营抉择，不评价制度优劣、不做意识形态判断。
2. **人物只写商业行为**：不涉及个人司法、私德、政治关系。
3. **敏感期审慎**：1949—1978 若纳入，只写商业组织形态的客观变化，不做评价。
4. **数字从严**：中国商业史的数字在中文互联网上以讹传讹极多，除非是教科书级共识（如深圳特区设立年份），一律定性表述。
5. **对照要克制**：echo 做结构对照，不做"中国版 XX"式的简单类比，也不做优劣排序。
